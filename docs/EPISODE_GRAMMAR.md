# ROAD BRAIN — Episode Grammar

## Current default carrier

Every current ROAD BRAIN episode should first be designed as a **five-state swipe comic**.

```text
SLIDE 1 — CLEAN / HOOK
SLIDE 2 — VIOLATION
SLIDE 3 — DIAGNOSIS
SLIDE 4 — ABSURD CONSEQUENCE
SLIDE 5 — CALM / CORRECT
```

Optional publishing extensions:

```text
SLIDE 6 — ALL-IN-ONE SHAREABLE COMIC
SLIDE 7 — PRISTINE RULE CARD
```

The viewer's swipe replaces the old fixed timeline.

## What each state means

### 1. CLEAN / HOOK — establish reality
Show a recognizable road situation immediately.

Rules:
- legible at feed size;
- one dominant visual idea;
- normal road geometry;
- sparse institutional text;
- if a guest/viral character is used, their expression or pose should help the viewer understand the situation before reading everything.

The hook should not be a generic title card. Start inside the offence or immediately adjacent to it.

### 2. VIOLATION — make the bad behaviour undeniable
The offence becomes explicit.

Rules:
- show exactly what the road user is doing wrong;
- introduce amber/status warnings;
- keep the physical road geometry easy to parse;
- one short joke is enough.

### 3. DIAGNOSIS — the institution notices
ROAD BRAIN classifies the behaviour with deadpan seriousness.

Useful devices:
- absurd system labels;
- reaction dialogue;
- bureaucratic annotations;
- mock telemetry;
- ceremonial titles;
- character transformation beginning.

This slide should reward the swipe from slide 2.

### 4. ABSURD CONSEQUENCE — psychic/bureaucratic rupture
This is the episode-specific escalation apex.

Rules:
- exaggerate the social consequence of the offence;
- break the subsystem relevant to the behaviour;
- use one memorable visual idea rather than generic visual noise;
- the underlying offence must still be inferable;
- this is usually the most screenshot-worthy slide.

Examples:
- unsignalled lane change → telepathy infrastructure collapses;
- lane hogging → Right Lane Raja establishes a sovereign kingdom;
- high beam abuse → headlamp classified as a local star;
- shoulder driving → shoulder reclassified as infinite private expressway.

### 5. CALM / CORRECT — boring competence
Hard reset to the actual correct behaviour.

Rules:
- clean diagram;
- no character heroics;
- no corruption;
- literal instruction;
- `DRIVE PREDICTABLY.` when appropriate.

The payoff is **nothing dramatic happens because the road user behaves normally**.

## Optional slide 6 — all-in-one shareable
Condense the full joke into a single multi-panel image.

Purpose:
- screenshotting;
- DMs;
- Stories;
- context survives outside the original carousel.

This slide may repeat previous art. Repetition is allowed because the distribution job is different.

## Optional slide 7 — pristine rule card
Use when the legal/factual instruction benefits from being isolated.

Keep it brutally simple.

## Caption hierarchy

Use these semantic roles:

```text
Caption/Rule
Caption/Violation
Caption/Reaction
Caption/System
Caption/Annotation
Caption/Endcard
Caption/Dialogue
```

### Rule
The actual behaviour to remember.

Examples:
- `INDICATE. THEN MOVE.`
- `DIM YOUR HIGH BEAMS.`
- `MOVE BACK LEFT AFTER OVERTAKING.`
- `THE SHOULDER IS NOT A LANE.`

### Violation
Literal diagnosis.

Example:
- `UNSIGNALLED LATERAL MOVEMENT DETECTED`

### System
Status / machine interpretation.

Examples:
- `ROAD STATE`
- `LANE OCCUPANCY: PERMANENT`
- `VISUAL INPUT DEGRADED`
- `ROAD WIDTH: INFINITE`

### Reaction
The institution momentarily reveals personality.

Examples:
- `TELEPATHY NOT SUPPORTED`
- `WHY IS THE SUN DRIVING TOWARD US`
- `TREATY NEGOTIATIONS FAILED`

### Dialogue
Use sparingly for characters. Dialogue should be shorter and less clever than the system text.

### Annotation
Small technical flavour. Never required to understand the rule.

### Endcard
Series-level closure.

Default:
- `DRIVE PREDICTABLY.`

## Escalation shorthand

```text
0 — recognizable reality
1 — offence
2 — institutional overanalysis
3 — reality/bureaucracy failure
RESET — calm correction
```

Not every episode needs maximal chaos. The contrast is more important than the quantity of jokes.

## Character casting rule

Guest characters may be drawn from current internet culture, but treat them as **actors cast into ROAD BRAIN archetypes**.

The durable label should be the ROAD BRAIN role, not the external meme.

Prefer:
- transformed reference;
- parody;
- archetypal pose/expression;
- original redraw;
- collage that clearly belongs to ROAD BRAIN.

Avoid direct dependence on copyrighted character artwork or an unmodified creator asset.

## The swipe test

Before export, ask:
1. Does slide 1 stop the thumb without requiring a paragraph?
2. Is the offence unmistakable by slide 2?
3. Does every swipe add a new beat rather than restate the previous slide?
4. Is slide 4 the funniest or strangest visual escalation?
5. Is slide 5 dramatically calmer than slide 4?
6. Can the rule be understood if all joke captions are removed?
7. Would someone send this to a friend who does the behaviour?
8. Does the post work completely without audio?
9. If a guest meme disappeared tomorrow, would the ROAD BRAIN archetype still make sense?
