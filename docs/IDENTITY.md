# ROAD BRAIN — Identity

## Identity thesis

ROAD BRAIN should look like a **glitched institution making transmissions**.

The identity is not built from a literal brain icon. The name already carries the metaphor. The visual system should feel like transport bureaucracy developing a neurological event.

## Wordmark direction

Primary wordmark:

```text
ROAD
BRAIN
```

Preferred treatment:
- stacked;
- circular or compact badge-friendly composition when useful;
- heavy neutral grotesk;
- minimal or no surrounding embellishment;
- one restrained transmission fault at most;
- black / off-white as default;
- signal amber only as a tiny status accent when needed.

The glitch should be subtle:
- one horizontal slice displaced;
- one tiny registration error;
- one brief animated fault;
- never a permanently shredded wordmark.

## Identity behaviour

Think in two states:

### CLEAN
- perfectly aligned wordmark;
- institutional;
- no corruption.

### FAULT / ACTIVE
- one portion shifts or misregisters;
- tiny amber status cue may appear;
- then reset.

The logo should be able to behave like the rest of the transmission system.

## Typography

### Primary
Use a heavy, neutral grotesk family.

Desired qualities:
- institutional;
- legible;
- non-fashionable;
- unromantic;
- capable of carrying both dry system labels and giant instructional statements.

Helvetica Neue / similar neutral grotesks are a useful reference direction, not a mandatory dependency.

### Secondary
Use a utilitarian monospaced face for metadata.

Examples:

```text
TRANSMISSION SYSTEM / RB-001
RBTV // TX-001
STATE: VIOLATION
SIGNAL: ABSENT
```

## Caption principle

ROAD BRAIN does not use “glitch typography.”

It uses **institutional typography that glitches**.

That distinction is important.

Messages remain short and assimilable. Distortion happens to the system around the instruction or momentarily to duplicate layers, not to the final rule itself.

## Tone examples

Institutional:
```text
DETECTION
WARNING
ERROR
ROAD STATE
```

Diagnostic:
```text
UNSIGNALLED LATERAL MOVEMENT DETECTED
VISUAL INPUT DEGRADED
EMERGENCY ROUTE OBSTRUCTED
```

Dry reaction:
```text
TELEPATHY NOT SUPPORTED
WHY IS THE SUN DRIVING TOWARD US
```

Instruction:
```text
INDICATE. THEN MOVE.
DIM YOUR HIGH BEAMS.
THE SHOULDER IS NOT A LANE.
DRIVE PREDICTABLY.
```

## Logo usage rule

Do not force the logo into every frame. ROAD BRAIN should often feel like an anonymous broadcast system. Use the wordmark for:
- account identity;
- covers/thumbnails;
- occasional transmission boot/end states;
- export slates;
- profile/avatar development.

The recurring grammar should do more branding work than a watermark.
