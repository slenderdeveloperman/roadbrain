# ROAD BRAIN

**Behavioral conditioning disguised as brain rot.**

ROAD BRAIN is an internet-native public-information comic system for Indian road behaviour. It takes extremely simple driving rules, presents them with deadpan institutional clarity, then lets the institution progressively lose its mind around the violation.

> **DRIVE PREDICTABLY.**

The joke may be complicated. The instruction cannot.

## Current locked decisions

1. ROAD BRAIN behaves like a **sentient road-safety institution**, not a generic meme account.
2. The default carrier is now a **swipeable static comic/carousel**, not a fixed-duration Reel.
3. The narrative grammar is five states: clean → violation → diagnosis → absurd consequence → calm/correct.
4. The viewer's swipe replaces the old timeline. Each slide must work instantly at phone size.
5. Existing viral internet characters may be used as **casting/reference energy**, while recurring ROAD BRAIN archetypes remain the durable roles. Avoid direct unlicensed copying of proprietary character artwork.
6. Paper/static composition is the default production environment. Motion tools are optional for adaptations, not required for every episode.
7. Surrealism belongs to the **violation**. The **correction stays boring**.
8. The core public-facing line is **DRIVE PREDICTABLY.**

## Publishing shape

Recommended carousel:

```text
Slide 1 — recognizable situation / hook
Slide 2 — violation
Slide 3 — institutional diagnosis / reaction
Slide 4 — absurd consequence / psychic rupture
Slide 5 — calm, boring correction
Slide 6 — optional all-in-one shareable comic
Slide 7 — optional pristine rule card
```

## Status

ROAD BRAIN is in active prototype production. EP001 is being re-authored as the reference swipe-comic implementation. Motion versions remain possible downstream, but static comics are now the default system.
